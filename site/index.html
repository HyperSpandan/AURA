Android TV and Google TV

The same APK opens a layout made for the TV, driven by the remote: the arrows go where you expect and seek through the song. Sign in by scanning a code with your phone instead of typing on the TV.

Install the universal APK with Downloader or any file manager on the TV; AURA joins the home screen's apps.

Windows, macOS and Linux

A desktop app with a sidebar, synced lyrics beside the page, the queue, Discord status and Last.fm scrobbling. On Windows 11 it draws its own title bar over Mica.

Not signed by Apple or Microsoft yet, so the first launch shows a warning. On a Mac, right-click the app and choose Open.
