A small API. No extension runtime.

AURA uses the BitChord HTTP add-on contract. Listeners add your service root or manifest.json URL inside Android Settings → Add-ons → Audio add-ons, or in the Web Player under Settings → Audio sources.

The starter is a Cloudflare Worker with a configurable catalog, CORS headers, and unit tests. Add your own media URLs and measured metadata before deploying.

cd examples/audio-addon
node --test worker.test.mjs
npx wrangler deploy

Configure CATALOG in wrangler.toml. Keep signed audio URLs short-lived and resolve them freshly during stream requests.

The three endpoints

Describe your service

GET/manifest.json
{
  "id": "org.example.catalog",
  "name": "My audio catalog",
  "version": "1.0.0",
  "resources": ["search", "stream"],
  "allowDownloads": true,
  "checkValidLossless": false,
  "settings": [{
    "key": "quality", "default": "lossless",
    "options": [{"label": "Best available FLAC", "value": "lossless"}]
  }]
}

Use a stable unique ID. Set allowDownloads: false if offline caching is prohibited, or checkValidLossless: true to restrict queries to supported wired, USB DAC, or HDMI outputs.

Find the recording

GET/search?q=title%20artist&quality=lossless
{"tracks": [{
  "id": "recording-42", "title": "Example Song",
  "artist": "Example Artist", "album": "Example Album",
  "duration": 203, "format": "flac",
  "artwork": "https://cdn.example.org/cover.jpg"
}]}
  • duration in seconds
  • no match → {"tracks":[]}

Return accurate titles, artists, and version qualifiers (live/remix). AURA verifies recording identity and duration before accepting matches.

Hand over the audio

GET/stream/recording-42?quality=lossless
{
  "url": "https://cdn.example.org/recording-42.flac",
  "codec": "flac", "format": "flac", "manifest": "none",
  "sampleRate": 96000, "bitDepth": 24,
  "encrypted": false
}
  • sampleRate in Hz
  • bitrate in bps
  • manifest: none, hls or dash

Describe the audio you serve.

Do not relabel lossy AAC or MP3 audio as FLAC or inflate advertised sample rates. Verify every file with ffprobe:

ffprobe -v error -select_streams a:0 \
  -show_entries stream=codec_name,sample_rate,bits_per_raw_sample \
  -of json recording.flac

Playback starts immediately while AURA checks eligible lossless add-ons in parallel, switching seamlessly without interrupting the listener.

Make delivery reliable.

Transport

Public HTTPS endpoints for manifests, redirects, and audio URLs. Private/local destinations are rejected on Android.

Browser Access

Include CORS headers on API, media, and HLS/DASH segment responses and answer preflight OPTIONS requests cleanly.

Seeking

Support HTTP Range requests and return 206 Partial Content with valid Content-Range headers.

Rate Limits

Respond with HTTP 429 and Retry-After. AURA seamlessly fails over to the next enabled source.

Failures

Return appropriate HTTP errors with {"error":"Reason"}. Never serve HTML error pages as audio bytes.

Size & Expiration

Keep JSON responses under 2 MiB (downloads max 512 MiB) and keep signed media URLs valid past 5-minute stream caches.
