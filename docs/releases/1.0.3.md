AURA 1.0.3 addresses reported issues with navigation, account switching, and web player UX, alongside general performance and stability improvements.

### Changes in this release
- **Explore Screen:** Fixed a crash when scrolling down into the Moods & Genres section caused by duplicate item keys from YouTube Music category payloads.
- **Account Management:** Fixed an issue where tapping "Add another account" caused the Google sign-in page to immediately bounce back due to existing cached session cookies and passive authentication flags.
- **Web Player UX:** Replaced favorite star with an interactive red heart for liked songs, refined layout scaling (110% main content zoom with standard 100% sidebar), and removed obsolete links.
- **Stability & Performance:** Improvements to audio stream resolution, session recovery, and offline caching reliability.

Install this update over your existing AURA installation; it shares the official signing identity and has a higher version code (`versionCode = 4`).

Choose **arm64-v8a** for most recent Android phones or **universal** if unsure. `SHA256SUMS.txt` contains APK checksums.
