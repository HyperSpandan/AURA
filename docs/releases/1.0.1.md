AURA 1.0.1 brings Listen Together enhancements, major voice note and audio call volume improvements, visual polish, and performance optimizations across the entire app.

### What's New & Highlights
- **Listen Together Capsule Navigation & Mini Player:** Refined the in-room interface to feature the sleek capsule navigation and player dock matching the Explore screen, with single-line room code display.
- **Dynamic Animated Island:** The "Just you here" / participants island now smoothly elevates with physics-based spring animation above the dock when expanded, ensuring it is never obscured.
- **Room Chat Notifications:** Receive system notifications for incoming room chat messages and voice notes when navigating outside the Listen Together screen.
- **High-Gain Voice Audio:** Substantially boosted microphone and playback volume levels with cubic soft-saturation curves to deliver loud, clear voice notes and room calls without harsh clipping.
- **Cover Glow & Splash Visuals:** Restored the original single-radial "Glow under the cover" aesthetic and fixed the startup logo transparency.
- **Low-End & Battery Performance Tuning:**
  - Downscaled frosted glass shader passes saving ~75% GPU fill-rate.
  - Adaptive memory cache sizing and system memory-trim (`onTrimMemory`) support to prevent background terminations.
  - Zero-allocation wordmark animation skipping recomposition and layout overhead during playback.
  - Stable list keys across Explore, Search, Library, and Rooms for stutter-free scrolling on any device.

### Installation
Install this update over your existing AURA installation; it shares the official signing identity and has a higher version code (`versionCode = 2`).

Choose **arm64-v8a** for most recent phones or **universal** if unsure. SHA256SUMS.txt contains the APK checksums.
